Attach files to pages and issues, and embed images right in the text.

## Images

In the editor, **paste** a screenshot, **drop** an image file onto the text, or use the paperclip button. Folio uploads it and inserts the Markdown for you, so the image shows in the preview straight away.

## Other files

At the bottom of any page or issue is an **Attachments** area. Drop files on it, or click **browse**. Each file lists its size, who added it and when. Delete it with the bin button.

## Good to know

- The size limit is 25 MB per file unless your administrator changed it.
- Images and PDFs open in the browser. Everything else downloads, including HTML, so an attachment can never run as a web page.
- Deleting a page deletes its attachments too.

> [!TIP]
> Name files clearly before uploading. `architecture-2026.png` beats `Screenshot (4).png`.
