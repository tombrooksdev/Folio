Pages are written in **Markdown**, a simple way to format text with plain characters. You never need to learn a toolbar.

## The essentials

```
# Big heading
## Section heading
**bold**  *italic*  `code`
- a bullet list
1. a numbered list
> a quote
[a link](https://example.com)
```

## Tables and tasks

```
| Name | Owner |
|---|---|
| Deploy | Sam |

- [ ] A task to do
- [x] A task that is done
```

## Panels

Callouts draw attention to something important. Start a quote with a type in brackets:

```
> [!INFO]
> Good to know.
```

> [!INFO]
> This is an info panel.

> [!WARNING]
> This is a warning panel. There are also `NOTE`, `TIP` and `SUCCESS`.

## Code

Fence code with three backticks and a language name. Every code block gets a **Copy** button when you hover over it.

> [!TIP]
> Headings automatically build the **On this page** outline on the right of every page.
