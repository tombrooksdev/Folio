A **space** is a home for one team or project. It holds that team's pages and its issues, so everything about a project lives side by side.

## Create or pick a space

Use **Create, Space** (or the plus beside *Spaces* in the sidebar). Give it a name and a short **key** such as `ENG`. The key becomes the prefix for issue numbers: `ENG-1`, `ENG-2`, and so on.

> [!INFO]
> You can't change a key later because it appears in links and commit messages. Pick something short and memorable.

## Inside a space

| Link | What it is |
|---|---|
| **Board** | The active sprint as columns |
| **Backlog** | Everything planned and unplanned |
| **Issues** | Search and filter all issues |
| **Reports** | Burndown, velocity and sprint history |
| **Code** | Linked GitHub repository |
| **Pages** | The page tree, with **Create page** at the top |

## Not sure where to start?

Use the **practice space**. It is a safe space with sample pages, an epic and a running sprint, so you can click around without worrying about your real data. Create it from the *Learn* home and delete it whenever you like.
