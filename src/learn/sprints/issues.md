Folio uses a small, fixed set of fields on purpose, so there is nothing to configure and everyone speaks the same language.

## Types

| Type | Use it for |
|---|---|
| **Story** | Something a user will notice |
| **Bug** | Something that is broken |
| **Task** | Everything else |

## Status

Three statuses cover almost every team: **To do**, **In progress** and **Done**. The board has one column for each.

## Priority and points

Priority is **high**, **medium** or **low**. **Story points** are a rough size (1, 2, 3, 5, 8). Don't agonise: points are for comparing work, not for measuring people.

## Where to work

- **Backlog** lists everything, grouped by sprint.
- **Board** shows the active sprint as columns.
- **Issues** searches and filters across the whole space.

> [!INFO]
> Points feed the burndown and velocity charts, so give issues a size before you start a sprint.
